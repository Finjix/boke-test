# MiniMax H3 视频处理工具

这是一个 Windows 桌面工具，使用 Tkinter 调用 MiniMax H3：

    单个视频（3–15 秒）
            ↓
    可选参考图（最多 9 张）
            ↓
    目标地区
            ↓
    H3-Context-IR 输出结构提示词
            ↓
    MiniMax-H3 生成视频
            ↓
    output/YYYYMMDD_HHMMSS.mp4

## 使用

双击 start_app.cmd。首次启动会自动准备项目内 Python、FFmpeg 和依赖。

在窗口中填写 MiniMax API Key，选择视频、可选参考图和目标地区，然后点击“开始处理”。

- 视频原始时长必须为 3–15 秒。
- 视频时长按四舍五入转换为 H3 支持的 4–15 秒整数；例如 3 秒按 4 秒提交。
- 输入视频会临时转为 H.264 MP4。
- 参考图最多添加 9 张，并以内嵌 Base64 方式发送。可在一次选择时按 `Ctrl` / `Shift` 多选，也可反复点击“添加（可多选）”累加；重复文件不会重复发送。参考图只用于人物、服装、材质、色彩与整体美术的外观风格，不得改变或复制动作、位置、构图、机位、镜头运动、时序或剪辑；这些内容严格以原始视频为准。请求体超过 MiniMax 64 MB 限制时会直接报错。
- 每个镜头的建筑、街景、道路设施、车辆、招牌、包装和可辨识文字都会按目标地区重建；源视频只保留故事、人物关系、表演、镜头和节奏。最终 H3 请求会再次附带这些硬规则，避免 Context-IR 将其省略。
- Context-IR 会被要求输出不超过 6,000 字符的精简镜头结构提示词，为最终 H3 的本地化硬规则预留空间；如果服务仍返回超长内容，工具会提示重试，不会裁剪已有镜头分析。
- 视频模型无法保证生成的阿拉伯文绝对准确、可读；需要可核对的商业文案时，仍应在生成后使用文字识别、跟踪和排版覆盖处理。
- 可点击“拼接视频”打开窗口，多选视频并通过上移/下移调整顺序，按列表顺序拼接后保存到 output 文件夹。
- 结果只保存到项目根目录的 output 文件夹。
- 任务结束后，临时 work 文件会自动清理，不保存历史、日志或任务恢复记录。

## 配置

Key 可以在 GUI 保存，也可以复制 .env.example 为 .env 后填写 MINIMAX_API_KEY。
分辨率默认为 768P，可在 .env 中改为 2K；GUI 不提供其他高级配置。
